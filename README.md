# Digital Signal Processing (DSP) Project

This project implements various digital signal processing techniques for audio signals, 
including spectral analysis, filtering, equalization, modulation, and visualization 
through a graphical user interface.

## Requirements

- Python >= 3.13

### Python Libraries Used
- numpy == 2.4.0
- scipy == 1.16.3
- matplotlib == 3.10.8
- sounddevice == 0.5.3
- soundfile == 0.13.1
- messagebox
